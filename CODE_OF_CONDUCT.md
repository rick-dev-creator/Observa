# Code of conduct

Observa is a small, single-maintainer project. The expectations are simple:

- Be respectful and constructive in issues, discussions, and pull requests.
- Critique code and ideas, not people.
- Keep conversations on-topic to the project's scope (macro financial observability).
- Assume good faith; ask questions before assuming intent.

Behaviour that does not meet these expectations — personal attacks, harassment of any kind, deliberately disruptive comments, or sharing other people's private information — will result in moderation: edits, removed comments, locked threads, or a ban from the repository at the maintainer's discretion.

If you experience or witness behaviour that violates this policy, report it privately to the maintainer via the email address listed on the [maintainer's GitHub profile](https://github.com/rick-dev-creator), or through GitHub's [report abuse](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) flow.

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/) without adopting its full text — the rules above are the maintainer's interpretation of those values for a project this size.
